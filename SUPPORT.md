# Support

## How to Get Help

- Open an issue for bugs, broken links, or unclear docs
- Use discussions (if enabled) for learning questions
- Include exact module path and command output when reporting problems

## What Maintainers Need

- Your environment (OS, Java, Maven versions)
- Steps to reproduce
- Expected behavior vs actual behavior
- Logs or stack trace

## Out of Scope

- Production SLA
- Private tutoring
- Immediate response guarantees

This project is community-maintained and best-effort.
