# Security Policy

## Scope

This repository is primarily educational and includes demo code.
Do not assume any sample is production-hardened.

## Reporting a Vulnerability

Please report security concerns privately to maintainers before opening a public issue.
Include:

- Affected path or module
- Reproduction steps
- Impact assessment
- Suggested mitigation (if any)

## Response Targets

- Initial acknowledgment: within 7 days
- Triage decision: within 14 days
- Public disclosure: after fix or mitigation is available

## Safe Defaults for Contributors

- Never commit secrets, tokens, or private keys
- Use placeholder credentials in examples
- Prefer least-privilege settings in demo configs
