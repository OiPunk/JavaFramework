# Spring Boot 2.x Quick Start: Intro and Hello World

## Objectives

- Understand MVC structure in a Spring Boot web project
- Create a Boot application from scratch in IDE
- Enable a productive local development workflow

## Topics

- MVC architecture basics
- Building a Spring Boot project
- Dependency injection in web controllers
- Hot reload / fast iteration setup

## Hands-on

1. Open one project under this folder (for example `FirstSpringBoot`)
2. Run:

```bash
mvn clean test
mvn spring-boot:run
```

3. Visit `http://localhost:8080`
4. Modify a controller response and verify quick reload behavior

## Checkpoints

- You can explain controller-service-view flow
- You can run and modify a Boot app locally
- You understand where to place config and static resources
