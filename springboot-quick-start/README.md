# Spring Boot Quick Start

Hands-on starter projects for Spring Boot web development.

## Modules

- `07-springboot-mvc-structure-dev-hot-reload/`: Boot project setup and MVC basics
- `08-springboot-web-datasource-thymeleaf/`: datasource + templates
- `09-project-thymeleaf-jpa-bootstrap/`: practical project assembly
- `10-mybatis-springboot-generator/`: MyBatis integration

## Typical Run Command

```bash
cd "07-springboot-mvc-structure-dev-hot-reload/FirstSpringBoot"
mvn spring-boot:run
```
