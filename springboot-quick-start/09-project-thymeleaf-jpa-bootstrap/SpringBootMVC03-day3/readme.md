# Spring Boot Project Development: Thymeleaf, JPA, Bootstrap

## Objectives

- Build a simple server-rendered web application
- Connect persistence layer with JPA
- Use Bootstrap for basic UI structure

## Prerequisites

- Completed basic Spring Boot MVC module
- Familiar with HTML and SQL basics

## Hands-on Outline

1. Configure data source and JPA settings
2. Build entity and repository layers
3. Render dynamic pages with Thymeleaf
4. Style views with Bootstrap

## Validation

- Data can be created/read from the UI
- Template renders server-side values correctly
- Project starts cleanly with Maven
