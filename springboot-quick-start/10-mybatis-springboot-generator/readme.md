# MyBatis Integration with Spring Boot

## Objectives

- Integrate MyBatis into Spring Boot
- Understand mapper-based persistence workflow
- Use MyBatis Generator for boilerplate reduction

## Key Concepts

- Mapper interface and XML mapping
- SQL-first persistence style
- Generator-driven model and mapper generation

## Hands-on

1. Open the project in this folder
2. Configure datasource and MyBatis settings
3. Run generation (if generator config is present)
4. Start app and test CRUD path

## Checkpoints

- Mapper methods execute expected SQL
- Spring Boot starts with MyBatis integration enabled
- Generated artifacts match schema
