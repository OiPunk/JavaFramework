# MyBatis Practice Module (Spring Boot Day 4)

## Objective

Apply MyBatis in a practical Spring Boot module and verify end-to-end database interaction.

## Learning Steps

1. Review project dependencies and configuration
2. Inspect mapper interfaces and SQL mappings
3. Run the project and validate one query + one write operation

## Validation Checklist

- Application boots without datasource errors
- Mapper scans successfully
- Query and insert/update paths both work

## Extension Exercise

Add one new mapper method with custom SQL and expose it through a REST endpoint.
