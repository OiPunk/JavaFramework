# Spring Family Overview and Environment Setup

## Objectives

- Understand what the Spring ecosystem solves
- Set up a local Spring development environment
- Build a minimal IoC-based sample project

## Prerequisites

- Java basics (classes, interfaces, packages)
- JDK 8+
- Maven 3.8+

## Lesson Outline

1. What Spring is and where it fits in Java development
2. Core modules in the Spring family
3. Environment setup (IDE, Maven, JDK)
4. First IoC container example

## Hands-on Steps

1. Open the module in your IDE
2. Import Maven dependencies
3. Run the first container bootstrap example
4. Confirm bean creation and dependency wiring

## Checkpoints

- You can explain IoC in one paragraph
- You can run a Spring sample from Maven
- You can identify where beans are declared and injected

## Exercise

Create a second service bean and inject it into the first one, then verify behavior with a simple test.
