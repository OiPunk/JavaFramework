# Glossary

- IoC (Inversion of Control): Delegating object creation and wiring to a container.
- DI (Dependency Injection): Supplying object dependencies externally.
- AOP (Aspect-Oriented Programming): Separating cross-cutting behavior from business logic.
- Bean: Object managed by the Spring container.
- Auto-Configuration: Spring Boot mechanism that configures components based on classpath and properties.
- Service Discovery: Dynamic registration and lookup of service instances.
- Circuit Breaker: Fault-tolerance pattern to prevent cascading failures.
- Tracing: Tracking requests across distributed services.
