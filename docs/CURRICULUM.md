# Curriculum

## Track A: Spring Fundamentals

### Module A1: IoC and DI

- Folder: `spring-quick-start/04-spring-ioc-quickstart/`
- Goals:
- Explain inversion of control and dependency injection
- Build and wire beans via XML and annotations

### Module A2: AOP Basics

- Folder: `spring-quick-start/05-maven-build-and-spring-aop/`
- Goals:
- Understand cross-cutting concerns
- Apply basic pointcut and advice patterns

### Module A3: AOP and Proxy Internals

- Folder: `spring/09-dynamic-proxy-source-analysis-2020-03-08/`
- Goals:
- Compare JDK dynamic proxy and CGLIB-like behavior
- Trace invocation flow from proxy to target

## Track B: Spring Boot Developer

### Module B1: Boot Setup and MVC

- Folder: `springboot-quick-start/07-springboot-mvc-structure-dev-hot-reload/`
- Goals:
- Bootstrap Spring Boot web project
- Understand project layout and hot reload workflow

### Module B2: Templates, Data Source, MyBatis

- Folder: `springboot-quick-start/08-springboot-web-datasource-thymeleaf/`
- Folder: `springboot-quick-start/10-mybatis-springboot-generator/`
- Goals:
- Configure datasource and template engine
- Integrate MyBatis with Boot and generator tooling

### Module B3: Boot Internals

- Folder: `springboot/04/`, `springboot/06/`, `springboot/07/`
- Goals:
- Explain startup sequence, auto-configuration, listeners
- Read source with a system-level mental model

## Track C: Spring Cloud Starter

### Module C1: Service Discovery and Calls

- Folder: `springcloud-quick-start/`, `springclooud/`
- Goals:
- Understand registration/discovery and client-side load balancing
- Compare `RestTemplate`, Feign, and gateway routing

### Module C2: Reliability and Operations

- Folder: `springclooud/07-circuit-breaker.md`, `springclooud/10-tracing-and-health-check.md`
- Goals:
- Learn circuit breaker, tracing, and health checks
- Identify minimum production-ready baseline

## Completion Criteria

A track is complete when you can:

- Run at least one module end-to-end
- Explain key concepts in your own words
- Finish one extension exercise beyond original sample scope
