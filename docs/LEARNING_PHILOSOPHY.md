# Learning Philosophy

## Why This Repository Exists

The goal is practical, code-first understanding of the Spring ecosystem.

## Standards for Educational Open Source Content

- Explain context before syntax.
- Include prerequisites and expected outcomes.
- Keep examples small and single-purpose.
- Prefer runnable steps over abstract theory.
- State known limitations and version constraints.

## Lesson Format Standard

Each lesson should include:

1. Objective
2. Prerequisites
3. Concept summary
4. Hands-on steps
5. Validation checklist
6. Extension exercise

Use [`STYLE_GUIDE.md`](STYLE_GUIDE.md) for writing details.
