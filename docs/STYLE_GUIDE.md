# Documentation Style Guide

## Language

- Primary language: English
- Keep wording simple and direct
- Avoid unexplained acronyms

## Lesson Document Template

```md
# Lesson Title

## Objective

## Prerequisites

## Key Concepts

## Hands-on

## Checkpoints

## Exercises

## Further Reading
```

## Naming

- Use `README.md` for folder entry pages.
- Use kebab-case for new English files.
- Keep legacy paths unchanged to avoid broken links.

## Code Snippets

- Include executable snippets only.
- Prefer short snippets that highlight one concept.
- Mention expected output whenever possible.
