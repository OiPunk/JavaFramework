# FAQ

## Is this a production framework?

No. This repository is primarily a learning and teaching collection.

## Why are some folders and files still in Chinese?

They are preserved as legacy source material. English entry docs are provided to improve accessibility.

## Which Java version should I use?

Use JDK 8 or JDK 11 unless a specific module states otherwise.

## Do I need Docker?

Not for most modules. Local JDK + Maven is enough for the core learning path.

## Can I contribute English rewrites of legacy lessons?

Yes. Follow [`../CONTRIBUTING.md`](../CONTRIBUTING.md) and the lesson template in [`STYLE_GUIDE.md`](STYLE_GUIDE.md).
