# Spring Boot Module

This folder focuses on Spring Boot concepts from web development basics to startup internals.

## Topics

- Configuration files and environment setup
- Template engine usage
- Datasource and persistence integration
- Startup process and auto-configuration internals
- Listener and embedded server behavior

1. `01/`

3. `03/`
4. `04/`

You should be able to build a small Boot service and explain what happens during app startup.
