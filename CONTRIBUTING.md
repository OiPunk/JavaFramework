# Contributing Guide

Thanks for contributing to the Java Framework Learning Lab.

## What to Contribute

- English rewrites of legacy Chinese lessons
- Better runnable examples
- Bug fixes in sample projects
- Missing explanations, diagrams, or checklists

## Contribution Workflow

1. Fork the repository
2. Create a feature branch
3. Make focused changes
4. Run validation steps for touched modules
5. Open a pull request with context and evidence

## Pull Request Checklist

- [ ] Scope is focused and easy to review
- [ ] Documentation is clear and English-first
- [ ] Commands in docs are runnable
- [ ] Existing paths are not broken
- [ ] Legacy content is preserved unless explicitly replaced

## Documentation Requirements

For lesson docs, follow `docs/STYLE_GUIDE.md`.
Every new lesson should include objective, prerequisites, and checkpoints.

## Commit Message Style

Use clear intent:

- `docs: add Spring Boot lesson checkpoints`
- `fix: correct datasource config in mybatis sample`
- `chore: normalize module README links`

## Code of Conduct

By participating, you agree to follow [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md).
