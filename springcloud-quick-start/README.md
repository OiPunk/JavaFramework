# Spring Cloud Quick Start

Introductory notes and code for microservice architecture with Spring Cloud.

## Topics Covered

- Service discovery
- Inter-service communication
- Gateway basics
- Session/cross-domain security examples

## Suggested Learning Flow

1. Read `SpringCloud02.md` to `SpringCloud08.md`
2. Explore `code/` examples
3. Review distributed session notes in `distributed-session-management/`

## Outcome

You should understand the minimum building blocks of a Spring Cloud microservice system.
